## 2. Content Requirements

### Homepage
- Clear H1 with primary tagline.
- Feature showcase with screenshots.
- Comparison table.
- FAQ section.
- Download CTA.
- Trust indicators (free, desktop, no subscription).

### Download page
- Platform selector (Windows, Linux, macOS).
- Artifact cards with type, version, size, checksum.
- Installation instructions per platform.
- Security note about unsigned builds.

### Windows page
- Windows-specific headline and copy.
- Key benefits of using Cambuz on Windows.
- Installation guidance (installer vs portable).
- SmartScreen warning explanation.
- Windows-specific FAQ.

### Lightweight page
- Editorial copy about what "lightweight" means.
- What is included vs deliberately excluded.
- Philosophy of focused software.

### Offline page
- Explanation of desktop vs web application.
- Offline capabilities list.
- Honest note about privacy (no blanket guarantees).

### Hindi/Punjabi page
- How rendering works with embedded fonts.
- Text extraction caveats (encoding-dependent).
- Three scenarios: standard Unicode, custom encoding, scanned.
- Clear explanation of why copied text can be wrong.

### Print page
- Step-by-step print workflow.
- Print capabilities list.
- Honest note about printer compatibility.

### Alternatives page
- Honest comparison table.
- Reasons to switch to Cambuz.
- Honest "when Cambuz might not be right" section.

## 6. Content Roadmap

Future articles and landing pages to consider. Each should be a genuinely
helpful resource, not a thin keyword-targeting page.

### Priority 1 — High value guides

1. **How to read PDF files on Windows** — A general guide covering different
   PDF readers, file associations, and reading tips. Target: beginners
   searching for help with PDFs on Windows.

2. **Hindi PDF text extraction: why copied text is sometimes wrong** — A
   technical explainer covering font encoding, Unicode vs custom encoding,
   and what users can do. Links to the Hindi/Punjabi landing page.

3. **How to choose a PDF reader** — A buyer's guide comparing categories
   (readers, editors, all-in-one suites) with honest recommendations based
   on use case. Links to the alternatives page.

4. **How to print PDF documents on Windows** — A step-by-step guide covering
   print preview, page ranges, paper sizes, and common printing issues.
   Links to the print landing page.

### Priority 2 — Supporting content

5. **What is a portable PDF reader and when to use one** — Explains portable
   vs installed applications, USB use cases, and restricted environments.

6. **PDF font encoding explained** — A technical article about how PDFs
   store text and why extraction quality varies.

7. **Free vs paid PDF readers: what do you actually get** — An honest
   comparison of what paid features exist and whether they matter for
   reading.

### Priority 3 — Future consideration

8. **PDF keyboard shortcuts for Windows** — A reference page for common
   shortcuts in Cambuz and other readers.

9. **Opening large PDF files: tips and tools** — Guide for handling very
   large documents.

10. **PDF reading on dual monitors** — Tips for reading PDFs in a
    multi-monitor Windows setup.

## 7. Deployment Notes

- **Production domain:** Update `productionDomain` in `src/config/site.ts`
  before deployment. This value is used for canonical URLs, sitemap, and
  robots.txt.
- **Sitemap:** `public/sitemap.xml` uses the production domain
  `https://cambuz.pixldot.com`. Update if the domain changes.
- **Robots.txt:** `public/robots.txt` references the sitemap at the
  production domain.
- **Google Search Console verification:** Add a verification meta tag or
  HTML file after deploying. The verification tag can be added to
  `index.html` or served as a static file in `public/`.
- **Analytics:** No tracking is installed by default. To add analytics,
  insert the tracking script in `index.html` or create a React component
  that loads analytics after user consent.
- **Structured data:** SoftwareApplication schema is included on the
  homepage, download page, and SEO landing pages. No ratings, reviews, or
  download counts are included in structured data.
